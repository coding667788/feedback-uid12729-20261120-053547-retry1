实现本地联邦身份目录。合成主体由同租户的多个提供方身份组成，每条关联边有两名提供方各自签发的模拟确认、双方身份当前代数及有效时间。将活动关联的连通分量作为主体，但一个分量不得包含同一提供方的两个身份。确认、续发、撤回可并发；解绑一条边后可能有桥接边继续连接，也可能把主体拆成多个。主体公开编号用分量最小身份 ID，任何成员集合或身份代数变化都分配新主体代数。

登录会话担保一组确切已确认身份、主体编号和当时主体代数；不同租户同编号隔离。新增关联的端点检查、合并或拆分、所有受影响会话的失效及持久回执同一 SQLite 事务。旧代数会话永不因分量又变回去而复活。事务内按租户非递减时钟重验确认及分量，已清除边的重复旧请求只能重放历史回执。

用独立进程固定两个单独合法的合并共同形成提供方冲突、撤回桥与备选路径并存、到期与新会话争用。真实终止自建进程于分量更新未提交及提交未回执两处，重启按 ID 重放。用独立重建组件的小模型对比每步代数与会话状态，明确拒绝时不得留下半个新主体。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
